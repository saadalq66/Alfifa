## Spin Studio — free 360° spin creator

[`spin-studio/`](spin-studio/) is a standalone, fully client-side web app that turns a
sequence of photos into an interactive 360° spin, with in-browser background
removal, view-only share links, embed codes and ZIP export. See
[spin-studio/README.md](spin-studio/README.md) for setup and deployment.

# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1AGK0xohR3ku8o4Y8On7CmSO1lQYvqAcP

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
